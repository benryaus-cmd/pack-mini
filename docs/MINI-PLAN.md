# PACK MINI implementation

Fork PACKVERSE 1.2 into the independent pack-mini repository. Source project remains unchanged. Scope: eleven chosen species, English/Japanese artwork slots with conservative image-crop deduplication and explicit source coverage audit; overlapping inventory-derived badge binders; market-referenced selling with badge-loss confirmation; four compact pack pools; local economy scaled tenfold; real reel and Matter.js pegboard motion; four-life retryable memory; room-first chat, reactions, threaded card offers/notifications with the existing mutual-confirm protocol; PopTron radio opt-in per session; stronger global foil and tactile pack audio; pinned Aippy import with one root and existing temp-save viewer access.

Storage stays in Game 2 with mini-lobby and separate record/board prefixes. Local saves/settings use packmini keys. Badges are derived rather than permanently awarded; owning the last required art keeps them, selling/trading it away removes them. ALL and thematic binders use artwork identity; language binders require their language slot. Sale payout is floor(USD market reference ×100 ×HAM factor): ungraded .5, HAM7 .3, HAM8 .7, HAM9 1, HAM10 2. Grading is one free roll per instance with35/35/25/5% probabilities and grades transfer unchanged. EUR-only pricing is converted by an explicitly sourced FX reference before a sale; unavailable quotes keep sale unavailable until a reference can be obtained. Show references/estimate labels rather than fabricated market prices.

Validation: catalogue species/available-image/dedup invariants; pack and tenfold economy; overlapping binders, last-copy badge loss, quote math and sale replay; deterministic physics/reload settlement; independent social clients including trade confirmations; mobile geometry, reel movement, four-life retry, daily hero hiding, all-surface foil and high/low images; actual pinned host import/build/loading.
